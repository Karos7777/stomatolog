# 🦷 DentBishkek — Интеллектуальный поиск лучшего стоматолога в Бишкеке

Комплексная программа для поиска, честной оценки и персонализированного подбора лучшего стоматолога и клиники в Бишкеке на основе байесовской модели доверия и верифицированных отзывов пациентов.

---

## 🌟 Возможности программы

1. **Глубокий реестр стоматологий Бишкека 2026**:
   - Точные адреса и геолокация всех известных клиник города (ул. Исанова, Боконбаева, Киевская/Эркиндик, Ахунбаева, 3-й микрорайон, Манаса, Джал-23, Токтогула, Коенкозова, Восток-5, городок Энергетиков).
   - Включает признанных лидеров: **Level Dent**, **Alpha Dental**, **Стоматология «32»**, **Клиника «Эстет» (Dr. Alex Soloshenko)**, **Expert Dental Studio**, **Metadent**, **Dental House**, **Детская стоматология «Солнышко»**, **Adis Dent**, **Simpladent**, **Smile Clinic 24/7**, **Family Dentistry Dr. Zheenbekova**, **СтомСервис**, **SOS Dent 24/7**, **Дента kg**.

2. **Пруфы образования, ординатуры и сертификатов**:
   - Данные об альма-матер (**КГМА им. И.К. Ахунбаева**, **КРСУ им. Б.Н. Ельцина**), годах окончания и высших категориях Минздрава КР.
   - Международные сертификаты с номерами и институтами выдачи (**Straumann Institute** (Швейцария), **Ormco Damon Master** (США), **Karl Kaps Dental Academy** (Германия), **AIC Osstem** (Южная Корея), **Malo Clinic** (Португалия), **EMS GBT** (Швейцария)).

3. **Полные прайс-листы по всем категориям (в сомах)**:
   - Конкретные цены на все процедуры: диагностика (КТ 3D, визиограф, iTero сканирование), терапия (лечение кариеса, каналов под микроскопом Karl Kaps / Zeiss), хирургия (удаление зубов мудрости), имплантация (Osstem, Straumann, Nobel, All-on-4), ортодонтия (Damon Q, элайнеры), ортопедия (цирконий, E.max виниры), профгигиена (Air Flow GBT) и седация во сне.

4. **Интерактивный калькулятор сметы лечения**:
   - Добавление процедур из прайс-листа в персональную смету в 1 клик.
   - Мгновенный расчет итоговой суммы и экспорт готового плана прямо в WhatsApp клиники.

5. **Режим сравнения клиник (Compare Mode)**:
   - Выбор до 3 клиник для сопоставления цен, квалификации врачей, стажа, оборудования и рейтингов бок о бок.

6. **Алгоритм честного рейтинга (Bayesian Rating)**:
   - Исключает фальшивых «лидеров» (врачей с 1 оценкой 5.0). Взвешивается по объему сотен проверенных отзывов **2ГИС** и **YDoc**:
     $$WR = \frac{v}{v+m} \cdot R + \frac{m}{v+m} \cdot C$$

7. **Интерактивная карта Бишкека (Leaflet.js)** и **Мастер подбора Smart Match**:
   - Расчет совместимости от 50% до 99% под вашу клиническую ситуацию.
   - Мгновенный переход в WhatsApp с предзаполненным сообщением.

## 🚀 Быстрый старт

### 1. Запуск веб-приложения (Рекомендуется)
```bash
python main.py
```
После запуска программа автоматически запустит веб-сервер и откроет в браузере:
👉 **http://127.0.0.1:8000**

### 2. Запуск консольного режима (Терминал)
```bash
python main.py --cli
```
или:
```bash
python cli.py
```
