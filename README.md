# 🦷 DentBishkek — стоматологи Бишкека, которым можно доверять

Выберите, что нужно (вылечить зуб, имплант, брекеты, ребёнку, срочно…) — сайт покажет лучшие клиники
и простыми словами объяснит по каждой: **есть ли лицензия Минздрава, честные ли отзывы и кто врачи**.

```
✅ Можно доверять                 Эстет Dr. Alex Soloshenko · 3-й микрорайон, 14/2
   ✅ Лицензия Минздрава найдена — НГМУ 4259, ОсОО «Клиника-студия Эстет»
   ✅ Отзывы хорошие: 4.9★ по 324 оценкам в 2ГИС
   ⚠️ Врачи известны, но дипломы не проверены
   ✅ Делают то, что нужно: имплантация; в лицензии есть хирургия; есть КТ
   [📞 Позвонить] [🗺 Открыть в 2ГИС] [Подробнее] [Проверить отзывы]
```

**Откуда данные (на 01.10.2026)** — всё со ссылками, ничего не выдумано:
- **Рейтинги, адреса и услуги 457 стоматологий** — официальный 2GIS Places API (`data/gis_bishkek.json`).
- **Лицензии** — реестр Минздрава КР (2420 лицензий, на 12.11.2025) и список МЗ «работающих без лицензии»
  ([med.kg/lisenzirovanie](https://med.kg/lisenzirovanie?locale=ru), `data/registry/`).
- **Врачи** — 405 публичных анкет YDoc: вуз, год, ординатура, отметка «Документы проверены» со списком сверенных
  документов (диплом, свидетельство об ординатуре…), отзывы, подтверждённые записью или звонком (`data/ydoc_doctors.json`).
- **26 клиник изучены вручную** (сайты, СМИ, ИНН).

## Как пользоваться

| Вкладка | Что делает |
|---|---|
| **Подобрать** | Нажимаете, что нужно → 5 лучших клиник с вердиктом ✅ / ⚠️ / ❌ и четырьмя проверками простыми словами. Можно «рядом со мной» и «только где врачи с проверенными дипломами». |
| **Врачи** | Все стоматологи с YDoc: где учились, что проверено, кто учился **за рубежом**, нет ли нестыковок (стаж больше, чем лет с выпуска; специальности без ординатуры). |
| **Все клиники** | Полный список с фильтрами по лицензии, числу оценок, 24/7. |
| **Проверить** | Отзывы клиники — **в один клик**: вводите название, получаете вывод. Врач или сертификат — вводите ФИО **или просто вставляете текст** с сайта клиники/сертификата: каждое утверждение разбирается автоматически. |
| **Как это работает** | Методика, ограничения, аудит прошлой версии. |

### Что значат вердикты

- ✅ **Можно доверять** — лицензия найдена в реестре, отзывы в порядке, красных флагов нет.
- ⚠️ **Можно, но проверьте** — нет красных флагов, но что-то не подтверждено (например, почти одни пятёрки или дипломы врачей не проверены).
- ❌ **Не рекомендуем без проверки** — есть красный флаг: лицензии нет в реестре, по адресу Минздрав выявил работу без лицензии,
  в лицензии нет нужного вида помощи (например, анестезии для «лечения во сне»), низкий рейтинг или противоречия в анкете врача.

## Как отличить накрученные отзывы от настоящих

Ни один признак не доказывает накрутку в одиночку. Считаем несколько независимых — те, что лучше всего работали в исследованиях:

| Признак | Как считаем | Основание |
|---|---|---|
| Копии текстов | Сходство ≥60% по символьным 5-граммам (MinHash + точная проверка); «Спасибо!» не считается | Jindal & Liu, WSDM 2008 |
| Всплески | 7-дневное окно, где отзывов ≥4× больше медианного недельного темпа, ≥80% положительных | Fei et al., ICWSM 2013 |
| Авторы-однодневки | Доля авторов с единственным отзывом **среди пятёрок по сравнению с остальными оценками** | Mukherjee et al., ICWSM 2013 |
| Похвала без деталей | Ни процедуры, ни врача, ни сроков, ни цены. Штраф только если таких >50% | Ott et al., ACL 2011 |
| «Закапывание» негатива | После отзыва на 1–2★ за 3 дня ≥3 пятёрок | Mukherjee et al., 2013 |
| Форма распределения | ≥93–97% пятёрок при ≥30 оценках — нетипично для медицины | Hu, Pavlou & Zhang, CACM 2009 |
| «Неподтверждённые» 2ГИС | Доля отзывов, которые антифрод 2ГИС вынес из рейтинга | Помощник 2ГИС |
| Расхождение площадок | Рейтинг на одной площадке выше других на ≥0.4★ | Mayzlin, Dover & Chevalier, AER 2014 |
| Скачок числа оценок | По истории снимков API: прирост в 4+ раза выше обычного темпа | Luca & Zervas, Mgmt Sci 2016 |

Конкретика в отзыве (процедура, врач, сроки, цена) **снижает** подозрение: такой отзыв дорого подделать.

**Проверка на синтетике** (`tests/test_reviews.py`): обычный поток отзывов получает 96–100 баллов из 100, накрученный — 24–40;
из заказных отзывов найдено ≥85% при ≤5% ложных срабатываний. Пороги откалиброваны на синтетических данных, на реальных
данных их стоит уточнить.

## Как отличить настоящий сертификат от «липового»

Проще всего — открыть вкладку **«Проверить»** и вставить текст, который клиника пишет о враче (или переписать с сертификата).
Каждое утверждение будет разобрано: что это за документ, что он доказывает, где его сверить и нет ли противоречий
(«ординатура раньше диплома», «стаж больше, чем лет с выпуска», «Master» от двухдневного курса).

### Врачи: что на самом деле проверено (на 01.10.2026)

| | Врачей |
|---|---|
| Анкет стоматологов Бишкека на YDoc | 405 |
| Указано образование | 46 |
| **YDoc сверил сканы документов** (диплом, у 8 — ещё и ординатура) | **11** — все учились в Кыргызстане (КГМА, КРСУ) |
| Указали учёбу за рубежом | 4 (Россия — 3, Турция — 1) |
| **Зарубежный документ проверен** | **0** |

«Документы проверены» на YDoc значит, что площадка сверила скан с ФИО врача, и анкета перечисляет, какие именно документы
сверены. Проверенной считается только та строка образования, для которой такой документ есть. Значок диплома рядом с
«Базовым образованием» стоит у всех анкет подряд и проверкой **не является**.

Зарубежная учёба определяется по названию вуза. Публично проверить её почти негде; исключение — **российские дипломы**:
попросите у врача серию, номер, регистрационный номер и дату выдачи и введите их с фамилией в «Сервис поиска сведений
о документах об образовании» на [obrnadzor.gov.ru](https://obrnadzor.gov.ru/) (госреестр ФРДО). Если диплома там нет, это
ещё не подделка: старые дипломы внесены не все.

Главное — не наличие бумаги, а **тип документа** и **кто может подтвердить**:

| Документ | Что доказывает | Где сверить |
|---|---|---|
| Лицензия МЗ КР | Клиника вправе оказывать эти виды помощи | [Реестр МЗ КР](https://license.med.kg/ru/), [Түндүк по ИНН](https://portal.tunduk.kg/public_services/opisanie/6323917), [elicense.gov.kg](https://elicense.gov.kg/) |
| Диплом вуза | Базовое образование стоматолога | Запрос в вуз (КГМА, КРСУ, ОшГУ) |
| Ординатура | **Настоящая** специализация (1–3 года) | Запрос в вуз |
| Сертификат специалиста / аттестация | Госдопуск к специальности | [elicense.gov.kg](https://elicense.gov.kg/license/id/2295) |
| Учёная степень | Защищённая диссертация | [НАК КР](https://vak.kg/rekvizity/) |
| Курс Straumann / Osstem / Ormco / Nobel… | 1–5 дней обучения работе с системой | Только запрос производителю. **Не специализация** |
| «Master», «Professor» от курса | Ничего: маркетинговое название | — |
| Награды, «лучший врач года» | Ничего: часто продаются | — |

Автоматические красные флаги: документ об ординатуре/аттестации датирован раньше диплома; стаж больше, чем лет с выпуска;
год в будущем; «звание» от коммерческого курса; громкое название эмитента («International Academy…»), которого нет в справочнике;
курс по имплантации у врача без хирургической специализации.

**Важно:** в 2025 году Минздрав КР проверил более 250 частных кабинетов, 138 работали без лицензии
([kaktus.media](https://kaktus.media/doc/531960_v_bishkeke_desiatki_stomatologiy_i_kosmetologiy_rabotaut_nelegalno._chem_eto_opasno_video.html)).
Проверка лицензии по ИНН — не формальность.

## Лицензии: что нашлось в реестре Минздрава

Каждая из 457 клиник сверена с реестром по адресу (улица + дом) и названию (латиница ↔ кириллица, ИП — по фамилии и имени врача):

| Результат | Клиник | Что значит |
|---|---|---|
| Лицензия найдена (адрес и название) | 59 | Совпали адрес и юрлицо/бренд или ИП врача этой клиники |
| По адресу есть лицензия на другое имя | 141 | Обычно ОсОО или ИП владельца — спросите, их ли это лицензия |
| Много лицензиатов в одном здании | 23 | Медцентры и бизнес-центры: чья лицензия — неизвестно |
| ИП врача клиники, но по другому адресу | 3 | Спросите, по какой лицензии врач принимает здесь |
| Лицензия на то же название, но другой адрес | 9 | Переехали или работают по чужому адресу |
| Госполиклиники | 8 | В реестре их и не должно быть: лицензируется только частный сектор (приказ МЗ КР №212 от 25.03.2013, п. 1.2) |
| **Нет в реестре** | **214** | Повод спросить номер лицензии (реестр может не учитывать лицензии до 2014 г.) |

ИП сверяется с врачами клиники по фамилии **и** имени: братья и сёстры с одной фамилией и отчеством («Шукуров Эрбол» и
«ИП Шукуров Уран») — разные люди, а опечатку в реестре («Видади»/«Вивади») прощаем, только если совпало и отчество.

Отдельно: **20 клиник находятся по точным адресам, где Минздрав выявил стоматологов, работавших без лицензии**:
ул. Шевченко, 6 (MedCity — 10 кабинетов, в т.ч. DentMen) и ул. Турусбекова, 13 (7 кабинетов) и др. По одному адресу
бывает много кабинетов, поэтому это не обвинение конкретной клинике, а повод спросить номер лицензии.

Проверяется и **объём лицензии**: если клиника рекламирует импланты, а в лицензии только терапия и ортопедия — это видно
(например, у ОсОО «Али-Мед» по адресу Али-Дент в лицензии нет хирургии). Если предлагают лечение во сне, а анестезии
в лицензии нет — красный флаг.

## Рейтинг доверия

`Индекс = 45% рейтинг с поправкой на объём + 25% подлинность отзывов + 25% лицензия и квалификация + 5% прозрачность`

Рейтинг с поправкой на объём — нижняя граница байесовской оценки: 5.0★ при 15 оценках весит меньше, чем 4.9★ при 500.
Пока отзывы не загружены, подлинность — нейтральные 70 баллов, минус 10 за «почти 100% пятёрок» при 100+ оценках
(так у 40 из 147 крупных клиник Бишкека — для медицины это статистически нетипично).

## Аудит прошлой версии

Прошлая база (15 записей) была сгенерирована **без источников**. Сверка с API 2ГИС и реестром МЗ КР:

- **Все номера сертификатов и лицензий выдуманы**: номеров вида `МЗ-КР-ЧЛХ-0482` в реестре Минздрава нет — настоящие выглядят как `НГМУ 4259` или `ИП 4401`.
- **У 7 из 15 завышено число отзывов** в 3–8 раз: Family Dentistry Dr. Zheenbekova — 332 против 43 оценок, Simpladent — 310 против 62, Adis — 290 против 65 (и рейтинг 4.88 против 4.1).
- **Неверные адреса** (Alpha Dental, Family Dentistry) и **выдуманные телефоны** вида `12-34-56`.
- **14 из 15 клиник реальны**, одна (SOS Dent 24/7) не найдена.
- Прошлая версия позволяла через API добавить отзыв и тут же поднять рейтинг — этот эндпоинт удалён.

> Поправка к первой версии этого аудита: тогда цифры брались из поисковой выдачи, и часть из них оказалась неточной
> (например, для Alpha Dental выдача давала 4.1★/17, а API — 4.9★/137; клиники «32», Family Dentistry и СтомСервис
> существуют). Теперь аудит пересчитан по официальному API.

Подробности: вкладка «Аудит» или `data/legacy_audit.json`.

### Посмотреть результаты с телефона, без запуска сайта

Сайт работает на вашем компьютере, поэтому с телефона по адресу `127.0.0.1` он не откроется. Вместо этого можно собрать
**снимок** — один HTML-файл с рейтингами, вердиктами и врачами. Он открывается на любом телефоне без сервера:

```bash
python -m tools.export_snapshot --out snapshot.html                 # для вставки в страницу Claude (Artifact)
python -m tools.export_snapshot --out docs/index.html --standalone  # обычная страница, например для GitHub Pages
```

В снимке есть подбор по задаче, врачи, все клиники и методика. Нет проверки вставленного текста (сертификат, тексты отзывов)
и «рядом со мной»: для них нужен запущенный сайт. Данные в снимке — на момент сборки.

### Открылась старая версия?

1. Свежая версия лежит в ветке `claude/eloquent-bardeen-0lj7gg`, а не в `main`. Проверьте: `git branch` — звёздочка
   должна стоять у этой ветки. Если нет: `git fetch origin`, `git checkout claude/eloquent-bardeen-0lj7gg`, `git pull`.
2. Закройте все окна терминала, где уже запущен сайт, и снова выполните `python main.py`. Если старая копия всё ещё
   занимает порт 8000, программа сама откроет новую на 8001 и предупредит об этом.
3. Внизу страницы и в терминале при запуске написана версия — должна быть «2.1 от 01.10.2026».

## Как обновлять данные

Ключ 2ГИС передавайте через переменную окружения и **никогда не сохраняйте его в репозиторий**:

```bash
export DGIS_API_KEY=ваш_ключ          # Windows: set DGIS_API_KEY=ваш_ключ
python -m tools.crawl_2gis            # все стоматологии Бишкека из API (~90 запросов демо-ключа)
python -m tools.license_registry      # свежий реестр лицензий и список «без лицензии» с med.kg
python -m tools.crawl_ydoc            # анкеты стоматологов YDoc (~400 страниц, 1 запрос в секунду)
python -m tools.import_reviews emmar отзывы.csv --unconfirmed 12   # тексты отзывов → анализ накрутки
```

`crawl_2gis` каждый раз **дописывает** снимок рейтинга в историю. Запускайте раз в 2–4 недели — по истории индекс
ловит резкие скачки числа оценок (след покупки пакета отзывов).

## Структура

```
app/
  models.py                 # модели: каждый факт — с источником, датой и способом получения
  scoring.py                # индекс доверия и его объяснение
  verdict.py                # вердикт простыми словами: лицензия, отзывы, врачи, подходит ли под задачу
  matching.py               # подбор под проблему пациента
  importers.py              # CSV / JSON / текст из 2ГИС
  database.py               # загрузка данных и сохранённых анализов отзывов
  api.py                    # FastAPI
  verification/
    reviews.py              # детектор накрутки отзывов
    licenses.py             # сверка с реестром лицензий МЗ КР
    doctors.py              # анкета врача: страна обучения, проверенные документы, нестыковки; разбор свободного текста
    credentials.py          # разбор документов о квалификации
    issuers.py              # справочник эмитентов и мест проверки
    text.py, dates.py
data/
  clinics.json              # 26 клиник, изученных вручную, со ссылками на источники
  gis_bishkek.json          # 503 стоматологии Бишкека из 2GIS API: рейтинги (с историей), услуги, премии
  ydoc_doctors.json         # анкеты стоматологов YDoc: образование, проверенные документы, подтверждённые отзывы
  registry/                 # реестр лицензий МЗ КР (Бишкек) и список «без лицензии»
  legacy_audit.json         # сверка прошлой версии
  review_analyses/          # результаты tools/import_reviews.py
examples/                   # СИНТЕТИЧЕСКИЕ отзывы для демонстрации (не о реальных клиниках)
tools/
  crawl_2gis.py             # все стоматологии Бишкека из 2GIS Places API
  crawl_ydoc.py             # анкеты стоматологов с YDoc
  license_registry.py       # загрузка реестров Минздрава с med.kg
  refresh_2gis.py           # обновление только 26 изученных клиник
  import_reviews.py         # анализ отзывов клиники в индекс
  synthetic_reviews.py      # генератор синтетики для тестов
static/, templates/         # веб-интерфейс
cli.py, main.py
tests/                      # автотесты (pytest)
```
